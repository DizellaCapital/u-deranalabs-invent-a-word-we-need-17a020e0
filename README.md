## The word

**wavenapped** — *At the school gate, you wave back warmly at a stranger, then watch them hug the person behind you.*

One new English word for the moment you wave back at someone who was never waving at you — your wave got kidnapped by the person standing behind you.

## How it runs

`main.py` (Python 3, standard library only) writes the single entry line to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`) and prints it:

```sh
python3 main.py
```
